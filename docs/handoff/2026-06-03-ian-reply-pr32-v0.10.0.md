## Why we relocated poker to `packages/services/builtin/poker/`

P2P-Hiverelay is positioned as generalized substrate. The
`packages/services/builtin/` directory already holds `ai-service`,
`schema-service`, `zk-service`, `arbitration-service`, `sla-service`,
`storage-service`, `identity-service` — all single-file services
extending `ServiceProvider` from `p2p-hiverelay/core/services/provider.js`.
PokerApp is the first first-class consumer of that pattern, and we have a
few more apps queued behind it. Keeping poker in `packages/core/core/`
would have diluted the substrate framing and parked the bus factor on a
poker-specific module in core's audit surface.

The factoring was cheap because your design already had the seam exactly
where we needed it: `PokerApp extends ServiceProvider`, payload is opaque,
HTTP/WS adapters are isolated, persistence is a separate adapter. Total
restructure cost: 8 file moves + 3 tiny edits + 5 test-script import
rewrites. No production code in core or services depends on the poker
module, so the move was internally invisible.

### Concrete decisions during the lift

- **HTTP/WS namespace stays at `/api/poker/*`.** Earlier I'd floated
  `/api/services/poker/*` as a single dispatch root, but existing
  services use each-claims-own-prefix (`/api/embed` in ai-service,
  etc.). Consistency with the existing convention wins over the
  dispatch-root tidiness.
- **`ServiceProvider` import** in
  `packages/services/builtin/poker/index.js` switched from the
  relative `'../services/provider.js'` (which was a core-internal
  path that no longer resolves from services) to
  `'p2p-hiverelay/core/services/provider.js'`. Matches every other
  builtin service.
- **`@noble/curves` added to `packages/services/package.json`.** Was
  workspace-hoisted from core, but the CP verifier imports it
  directly so it should be a first-class services dep.
- **`packages/core/core/index.js`** no longer re-exports the poker
  symbols; same for the `./core/poker/*` block in
  `packages/core/package.json`. Consumers import from
  `p2p-hiveservices/builtin/poker/*` going forward.
