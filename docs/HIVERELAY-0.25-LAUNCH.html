What we're standing up

Ten workstreams, one coherent ship

0.25 isn't a single feature — it's the wiring that turns a bare seeder into an always-on utility relay apps can call, operators can monitor, and the network can depend on.

🧅

Tor as a packaging default

Docker Compose, the systemd unit, and the Umbrel appliance set HIVERELAY_TOR=1 with SOCKS, control, persistent-key, and minimum-daemon wiring. The Node CLI translates those values into first-boot config defaults; explicit CLI flags and persisted config.transports.tor / config.tor.* win. A configured default is not proof of a live onion: signed advertisement still requires daemon readiness, descriptor health, and the restricted-endpoint negative probe.

Capability path G4-T route separation
⚙️

Utility services, declared in packaging

Outboxlog, notify, storage-proof, VRF, witnesslog and repairticket can be selected by HIVERELAY_* first-boot defaults on both Node and Bare paths. Persisted config.json wins over environment defaults, and <storage>/services.json is the final authority, including an explicit disable. Packaged OutboxLog uses a finite partitioned-Hypercore journal; notify remains non-live until an operator supplies a private APNs/FCM/WebPush descriptor; shard-store stays opt-in for disks that can carry it.

  • outboxlog
  • notify
  • vrf
  • witnesslog
  • repairticket
  • storage-proof

VRF HTTP surface

Verifiable randomness is now reachable over HTTP for apps that need leaderless sortition, fair ordering, or unbiasable beacons.

GET /api/v1/vrf/beacon-info
GET /api/v1/vrf/beacon-latest
POST /api/v1/vrf/select
Unlockson-chain-style fairness for p2p apps
🔔

Notify push provider resolution

The relay-hosted encrypted wake-up service now resolves a webpush descriptor to a live, non-memory provider — and fails closed on bad config so a misconfigured box never silently drops wakes.

Unlocksasynchronous p2p apps that wake on event
🧰

Client SDK helpers

HiveRelayClient gains first-class methods for the new surfaces — notify send/watch, shard put/get, witness append, and VRF beacon-latest — so app developers stop reimplementing transport.

  • shard

  • vrf

Dashboard panels

Operators get visibility into the two new live surfaces: a notify manage-status aggregate panel and a VRF panel. What the relay is actually doing is now on the dashboard, not buried in logs.

Unlocksoperator observability for G1 services
🛡️

Outboxlog durability & lifecycle

Journal and torn-tail audit paths are covered, loadRegistry() is split from reseedDrives() so recovery can seal storage-admission before reseed, and bytes-per-day metering is honest under restart.

  • journal
  • takedown audit
  • storage-authority close
🩺

Fleet health watchdog

systemd couldn't recover an event-loop hang — the main PID stayed alive, so Restart= never fired. A new local watchdog pings /health every 2 min and SIGKILLs + restarts on two consecutive failures, now rolled across every reachable box.

Unlocks12/13 fleet healthy vs repeated hangs
🧱

utah-8gb remigrate + memory

The 8.6 GB bloated RocksDB was quarantined and rebuilt from cores/; RSS fell from 5.5 GB to ~110 MB. Added 4 GB swap, dropped the thrashing MemoryHigh soft-lock, and kept the full feature plugin set.

  • CS7 rebuild
  • swap
  • MemoryMax=6G

The honesty ladder

Capabilities, by rung

Every feature maps to a privacy / integrity rung. We badge only what's evidenced — never what's "coming soon."

G0Live
Integrity
Can't forge bytes or signatures. Hypercore Merkle roots + signed envelopes. The foundation the whole stack is built on.
G1Live
Payload opacity
Encrypted, signed envelopes; utility services HTTP. 0.25 makes this fleet-wide and app-reachable.
G2-SPartial
Storage-schema opacity
Blind cells — no app semantics at rest. Code exists; blind public-test pilot runs in parallel (Track B).
G3Partial
At-rest unlinkability
BlindShard / cells + multi-relay cohort. shard-store code complete; not fleet-wide until 0.26.
G4-TPartial
Route separation
Tor onion path. 0.25 ships the packaging default; host deploy + negative-probe still uneven.
G2-WSpec'd
Wire opacity
Split transport (OHTTP + Protomux). Wire layer is built in the vnext blind-protocol package — OHTTP key config, transport-error taxonomy, ingress/gateway roles, and the full FORWARD family with flow control. Missing: the runtime, BlindTransportDescriptorV1, and the merge to main. Lands after 0.26.
G4-IResearch
Read-interest privacy
Bucket / PIR patterns for "can't tell which post I read." Optional research track, not on the near map.
G5Never (public)
Active-reader resistance
Impossible for public data. We document this on every public explainer rather than claim it.

Ship 8after Ship 2

Ship 11never

Documented as unachievable and badged on every public explainer. Some rungs you earn; this one you respect by not claiming it.

⚠️ What 0.25 is NOT

We hold ourselves to evidence-graded badges. These are the claims you will not hear from us about this release:

"Stable fleet is 0.25"
Stable remains 0.24.3 until canary soaks green.
"Tor is live on every relay"
Status shows no onion until host Tor + cookie control + upgrade evidence. Packaging is the path, not the proof.
"Blind substrate is GA / in 0.25"
Blind public-test is a parallel version line and lease, on ≤2 pilot nodes.
"The browser is a full DHT peer"
Still false. We use honest stack language — the browser is a client of the relay.
