6. Critical path — ordered remaining work

Near-term (unblocks cutover narrative)

  1. Fix Peerit vote materialization on HiveRelay OutboxLog path; re-run proof:hiverelay-outboxlog to full green.
  2. Arm production admin secret on outbox host; one synthetic suppress/unsuppress drill + log archive.
  3. Staging dual-run with relayBackend: hiverelay-outbox (not production flip yet).
  4. Merge/land operator data-layer PR #198 when CI green (dashboard observability for ops).
  5. Linux WAL Phase-0 fleet rerun on blind profile (freeze holdout).

Relaunch / GA (hard gates)

  1. Second independent operator + multi-origin signed roster (kill singleIngressWriter).
  2. Induced failure recovery — one-relay loss with write continuity.
  3. 2k-client staging (100/500/1k/2k) p99 < 2s, error budgets, RSS.
  4. Two PearBrowser devices + real iOS persistence proof.
  5. Gateway G7–G13 then optional public delivery cutover.
  6. Editorial v3 content + archive test boards.
  7. GA soak window + claim-lint (no overclaim).
Claim discipline: today you can say “public writable canary on HiveRelay-backed outbox plane; giga substrate largely shipped on integration lanes.” You cannot say multi-operator durable, marketing-scale ready, or full HiveRelay messaging path green until the vote fix + multi-ingress land.
